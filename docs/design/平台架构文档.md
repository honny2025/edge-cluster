## 一、整体架构

```
浏览器（React 单页应用）
   │  HTTP /api/v1/*（X-Auth-Token 头鉴权）
   │  WebSocket /ws/dashboard（大屏实时事件）
   ▼
FastAPI 平台服务（server/app，SQLite WAL）
   │  WebSocket /ws/agent（长连接，由 Agent 主动发起）
   ▼
node-agent（跑在手机 Termux 里的 Python 进程）
```

- **单端口交付**：平台把 `web/dist` 构建产物挂在自己端口（默认 8000）上，前端 `/api`、`/ws` 都是相对路径，天然指向后端。
- **平台从不主动连手机**：WebSocket 长连接由 Agent 发起，平台只被动接受。
- 后端统一前缀 `API_PREFIX = /api/v1`（见 [server/app/main.py:46](../../server/app/main.py#L46)）。
- 鉴权：共享 token 走 `X-Auth-Token` 头（前端 [api.ts](../../web/src/api.ts) 里 `resolveToken()` 解析 localStorage / URL / 默认值）。

### 2.2 全局外壳（App.tsx）

**顶栏**：平台名 + 版本号 · 实时通道状态点（已连接/重连中/连接中）· 三个计数徽标（在线/离线/从未上线）· 刷新按钮。

**侧边导航（Menu）**：总览 / 节点 / 模型库 / 部署 / 服务 / 文件 / 审计 / 系统 / 接口文档（`/docs` 新窗口打开 FastAPI 自带文档）。

**后台行为**：
- 维持一条 `/ws/dashboard` WebSocket，收到节点上下线事件时广播 `edge-cluster:node-event` 自定义事件，各页面监听后立即刷新。
- 断线按指数退避重连（1s → 2s → 4s … 封顶 30s）。
- 平台运行信息每 10s 轮询一次。
