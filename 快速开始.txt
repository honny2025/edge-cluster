======================================================================
 手机边缘计算集群管理平台 · 快速开始
======================================================================

这个文件夹就是完整的系统。不需要安装，复制走就能跑。

（第一次在新电脑上，建议先双击「环境初始化.bat」跑一次：自动补装
  WebView2 运行时 + 放行防火墙 8000 端口。只在本机跑模拟、不让手机连
  的话可以跳过。）


----------------------------------------------------------------------
 Windows：三步跑起来
----------------------------------------------------------------------

   1) 双击  启动.bat
      （推荐方式，它自动绕过 PowerShell 的脚本执行限制）

   2) 等它跑完（二进制已编译好，通常几秒内就绪）

   3) 浏览器打开  http://127.0.0.1:8000

   停止：双击  停止.bat


 想用命令行而不是双击的话，两种写法都可以：

   .\start_all.ps1                                          # 可能被拦，见下方
   powershell -ExecutionPolicy Bypass -File .\start_all.ps1  # 一定可以

   可选参数：
   .\start_all.ps1 -Nodes 5           # 起 5 个模拟节点
   .\start_all.ps1 -NoNodes           # 只起平台
   .\start_all.ps1 -DevWeb            # 额外起前端开发服务器（改前端用）
   .\start_all.ps1 -Port 8001         # 换平台端口（模拟节点会自动跟着换）


----------------------------------------------------------------------
 Linux / macOS
----------------------------------------------------------------------

   包内没有 Linux/macOS 的预编译二进制，需先装 Rust 工具链再编译：

   1) cd server-rust   && cargo build --release && cd ..
      cd node-agent-rust && cargo build --release && cd ..

   2) bash start_all.sh

   3) 浏览器打开  http://127.0.0.1:8000

   停止：bash stop_all.sh

   注意：zip 不保留 Unix 可执行权限，所以上面用的是 "bash start_all.sh"
   而不是 "./start_all.sh"。想用 ./ 方式的话先执行：
       chmod +x start_all.sh stop_all.sh


----------------------------------------------------------------------
 运行前需要装什么
----------------------------------------------------------------------

Windows 10/11（x64）用户：什么都不用装。

   本包已带编译好的 Rust 二进制（edge-cluster-server / edge-cluster-agent /
   桌面壳 edge-cluster-desktop）和构建好的控制台（web/dist），SQLite 已
   静态链进二进制，所以解压即用，无需 Python / Rust / Node.js。

   只有改代码时才需要额外装：
   * 改后端 / Agent 源码重新编译 → Rust 工具链（cargo）+ C 链接器
   * 改前端界面重新构建       → Node.js 18+（npm install && npm run build）
   * 跑 docs/acceptance/ 验收脚本 → Python 3.10+

   改前端时可用环境变量 EDGE_NODE 指定 Node 所在目录：
     $env:EDGE_NODE = "D:\node"
     powershell -ExecutionPolicy Bypass -File .\start_all.ps1 -DevWeb

   启动脚本不写任何系统目录、不改注册表 —— 卸载就等于删掉这个文件夹。


----------------------------------------------------------------------
 端口 8000 被占用 / 想换端口
----------------------------------------------------------------------

   .\start_all.ps1 -Port 8001

   模拟节点会自动连到新端口，不需要改任何配置文件。

   如果脚本提示"端口已被占用，平台起不来"，但平台其实已经在跑，
   那直接打开 http://127.0.0.1:8000 就行（换过端口就用你换的那个），不用再启动一次。


----------------------------------------------------------------------
 ★ 如果提示"禁止运行脚本" / "无法加载文件 xxx.ps1"
----------------------------------------------------------------------

这是 Windows 的 PowerShell 默认安全策略，不是你装的系统有问题。
报错长这样：

   无法加载文件 ...\start_all.ps1，因为在此系统上禁止运行脚本。

三种解法，任选一种：

   ① 直接双击 启动.bat          <- 最省事，推荐
   ② 用完整命令启动：
        powershell -ExecutionPolicy Bypass -File .\start_all.ps1
   ③ 一次性放开当前用户的脚本权限：
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
      之后 .\start_all.ps1 就能直接跑了。

   （补充：在某些自动化/非交互环境里，脚本被拦时是"静默失败"——不报错
     也不执行。如果发现什么都没发生，直接用方式 ① 或 ②。）

----------------------------------------------------------------------
 ★ 升级时不要"覆盖解压"（实测会丢文件）
----------------------------------------------------------------------

   PowerShell 的 Expand-Archive 加 -Force、或解压到一个已存在的目录，
   会先把目标目录清干净、然后又不写文件 —— 而且不报错。

   实测：同一个 zip 解压两次，第二次之后目录里的文件从 85 个变成 0 个。

   正确做法（任选一种）：

     ① 解压到一个新文件夹，然后把旧的这几处拷过去，再删掉旧文件夹
          server-rust\data\            平台数据库（节点列表 + 历史指标）
          node-agent-rust\state\       节点身份文件（拷走可保持 node_id 不变）

     ② 确认不需要旧数据后，直接删掉旧文件夹，再解压一次

   注意别把上面那两个目录当垃圾丢掉，它们不在 zip 里。
   （用 7-Zip 之类逐文件解压的工具一般不会触发这个问题，但仍建议按上面做。）
